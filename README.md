# AI-Based-Object-Detection-System
An AI-based object detection system using Python, Flask, YOLOv8 and OpenCV.

## Project Overview

An AI-based object detection system developed using Python, Flask, and YOLOv8. The system detects and identifies multiple objects from uploaded images.

## Technologies Used

- Python
- Flask
- YOLOv8
- OpenCV
- SQLite
- HTML
- CSS
- JavaScript

## Features

- User Login and Signup
- Image Upload
- Object Detection
- Object Counting
- Confidence Score
- Detection History
- Dashboard

## Project Modules

1. User Authentication
2. Image Upload
3. Object Detection
4. Result Display
5. Detection History
6. Dashboard
